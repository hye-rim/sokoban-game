# 소코반 📦

상자를 밀어 목표 칸에 모두 올리는 소코반(창고지기). [작은 오락실](https://github.com/hye-rim/smallgame)의 게임 중 하나. 의존성 없는 정적 게임(`index.html` + `logic.js` + `levels.js` + `game.js`)입니다.

- 나는 상하좌우로 한 칸씩 움직이고, 앞에 상자가 있으면 **민다**. 상자는 **당길 수 없고**, 한 번에 **하나만** 밀 수 있다 (상자 뒤가 벽이나 다른 상자면 못 민다)
- 상자를 전부 노란 목표 칸에 올리면 클리어. 목표에 올라간 상자는 초록, 구석에 박혀 더는 못 움직이는 상자는 빨갛게 보이고 알려 준다
- ↩ 되돌리기(Z)는 제한이 없다. 🔄 다시(R), ☰ 단계 선택. 이동은 방향키·WASD, 폰은 ▲◀▼▶ 버튼이나 판을 밀어서(스와이프)
- 30단계. 쉬운 것(상자 1개, 2번만 밀면 끝)부터 어려운 것(상자 4개, 최소 25번 밀기)까지. 단계는 아무 때나 골라서 할 수 있다
- ⭐ 별: 최소 밀기 수(par)로 풀면 3개, 그 1.5배 안이면 2개, 그보다 많으면 1개. 단계마다 가장 좋은 기록(별·이동 수·밀기 수)을 저장한다 (`sokobanDone`), 로비에는 깬 단계 수(`sokobanCleared`)가 보인다
- **레벨은 직접 만들었다**(기존 소코반 판을 쓰지 않음): `tools/generate.js` 가 목표 칸에 상자를 놓은 '다 푼 판'에서 거꾸로 끌어당기는 너비 우선 탐색으로 방마다 가능한 판을 모아 어려운 것을 고르고, `tools/solver.js` 가 앞으로 풀어 **가장 적게 미는 횟수(par)가 같은지·실제 규칙으로 재생해 클리어되는지** 확인한 뒤 `levels.js` 에 쓴다. 그래서 모든 단계는 반드시 풀 수 있다

규칙은 `logic.js`(화면 없이 Node 로 시험할 수 있다), 레벨은 `levels.js`, 화면·입력·소리는 `game.js`. 시험은 `node --test` (`test/logic.test.js` 규칙, `test/levels.test.js` 30단계가 풀 수 있고 par 와 같은지).

## 레벨 다시 만들기
```bash
node tools/generate.js 12      # 방 모양 수(기본 12), 3분쯤 걸린다 → levels.js 를 새로 쓴다 (씨앗을 바꾸려면 두 번째 숫자)
```
